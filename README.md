# 坦克大战（Battle Tank）

一个使用**原生 HTML / CSS / JavaScript** 实现的坦克大战小游戏，无任何第三方依赖，直接双击即可运行。

## 功能特性

- 🎮 玩家坦克：方向键 / WASD 移动，空格 / J 射击
- 🤖 敌方坦克：AI 自动移动与射击，按波次从顶部刷新
- 🧱 障碍物：**砖墙**（可被子弹摧毁）与**钢墙**（不可摧毁）
- 🏳️ 基地：位于底部中央，被敌人摧毁即失败
- ❤️ 生命值：玩家拥有 3 条生命，被击中后重生并短暂无敌
- 💥 碰撞检测：坦克-地形、坦克-坦克、子弹-地形、子弹-坦克
- 🏆 胜负判断：消灭全部敌人即胜利；生命耗尽或基地被毁即失败
- 🔁 重新开始：随时按 `R` 或点击按钮重开一局
- 📊 计分：每消灭一个敌人 +100 分

## 操作方式

| 操作 | 按键 |
| ---- | ---- |
| 移动 | `方向键` 或 `W` `A` `S` `D` |
| 射击 | `空格` 或 `J` |
| 重新开始 | `R` 或点击「重新开始」按钮 |

## 运行方法

本项目为纯静态页面，**无需安装任何依赖或构建工具**，任选其一：

1. **直接打开**：双击 `index.html`，用浏览器打开即可游玩。
2. **本地服务器**（推荐，避免个别浏览器的文件协议限制）：
   ```bash
   # 在项目目录下执行以下任一命令
   python -m http.server 8000
   # 或
   npx serve .
   ```
   然后浏览器访问 <http://localhost:8000>。

## 项目结构

```
tank-battle/
├── index.html   # 页面结构（画布、HUD、胜负遮罩）
├── style.css    # 样式（深色主题、响应式缩放）
└── game.js      # 游戏逻辑（地图、坦克、子弹、碰撞、AI、渲染）
```

## 实现说明

- **地图**：以「先全空、再按坐标填充障碍块」的方式生成，共 26×26 个格子，每格 24px。
- **移动**：坦克逐格移动，相邻两格之间做插值动画，移动时检查目标格是否可通行。
- **碰撞**：子弹使用连续像素坐标逐帧检测；坦克之间通过「当前格 + 目标格」双重占位避免重叠。
- **AI**：敌人按随机时间间隔决策「开火 / 前进 / 转向」，被阻挡时随机选择一个可通行方向。
- **测试**：`game.js` 末尾含一个仅测试环境生效的调试句柄（浏览器中 `module` 未定义，不执行），用于自动化校验各条战斗与胜负路径。
